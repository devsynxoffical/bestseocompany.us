Free SEO Audit Tool

Enter a URL and get an instant check of that page's technical and on-page SEO basics. The tool runs live through our API and shows results on screen in seconds.

How it works.

  1. 1

    Enter a URL

    Paste the full address of the page you want to check, such as your homepage or a key service page.

  2. 2

    We fetch the page

    Our API requests the page like a browser would, follows any redirects, and reads the HTML that comes back.

  3. 3

    Review the checks

    Each check shows a pass, warning, or issue with a short note on what it means and how to fix it.

What you get.

Status, redirects, HTTPS, and speed

We record the HTTP status code, any redirect chain, whether the page uses HTTPS, the response time, and the page size. A page that errors, redirects in loops, or loads slowly is harder for people and search engines to use.

Title tag and meta description

We check that both exist and flag lengths that are likely to be cut off in search results. These tags shape how your page looks on Google and whether people click.

Headings and content

We count H1 tags, show the heading structure, and count words on the page. One clear H1 and logical subheadings help readers and search engines follow the topic.

Indexing signals

We read the canonical tag, meta robots, and any noindex directive, and check for robots.txt and sitemap.xml on the site. A wrong canonical or a stray noindex can keep a page out of Google entirely.

Mobile, language, and social tags

We check the viewport tag, the html lang attribute, and Open Graph tags. These affect mobile display, language targeting, and how links look when shared on social platforms.

Structured data, images, and links

We list the JSON-LD schema types found, measure image alt text coverage, and count internal and external links. Schema can make pages eligible for rich results, alt text helps accessibility, and internal links help Google find your pages.

What this audit covers

The tool checks one page's technical and on-page basics. It looks at what's in the HTML and how the server responds. It also checks whether your site has a robots.txt file and an XML sitemap.

It does not check backlinks, rankings, or traffic. It does not crawl your whole site or run a full JavaScript render. For links, traffic, and rankings, use our free report tools.

How to use the results

Fix issues first, then warnings. A noindex tag or error status on an important page should be fixed right away. A slightly long title is a smaller task.

Run the tool on each of your most important pages. Different templates often have different problems, so checking your homepage alone can miss issues on service or product pages.

When you need more than a single-page check

Sites with many pages, indexing gaps, or recent traffic drops need a full technical review. Our free 40-point audit covers your whole site, local presence, and links, reviewed by a person on our team.
